# Plano 01-01: Fundação & Dados

**Fase:** 1 — Fundação & Dados
**Objetivo:** App React+Vite+TS rodando com modelo tipado, persistência localStorage, rotas e Home.
**Requisitos cobertos:** HOME-01, HOME-02, SET-04, NFR-01

## Tarefas

1. **Scaffold:** `package.json` (react, react-dom, react-router-dom, vite, @vitejs/plugin-react, typescript, vitest), `tsconfig.json`, `vite.config.ts`, `index.html`, `.npmrc` se preciso. `npm install`.
2. **Modelo (`src/types.ts`):** `ParametroKey` (10 chaves), `ParametroDef { key, label, grupo, min, max, tipo }`, `PARAM_DEFS` na ordem física do pedal com cores por grupo; `Parametro { valor, ativo }`, `Setup { id, nome, tagIds[], parametros, criadoEm, atualizadoEm }`, `Tag { id, nome, criadoEm }`; `createDefaultParametros()` (tudo 0/ativo); `clampParam()`.
3. **Storage (`src/storage.ts`):** camada localStorage versionada (`cuvave:setups`, `cuvave:tags`): list/get/create/update/remove/duplicate setups; list/createOrGet (normalização trim+case-insensitive)/rename/remove tags com contagem de uso; seed vazio; tratamento de JSON corrompido.
4. **App shell:** `src/main.tsx`, `src/App.tsx` com rotas `/`, `/setups`, `/setups/novo`, `/setups/:id`, `/tags`; `src/styles.css` com tema escuro do pedal e layout responsivo base.
5. **Home (`src/pages/Home.tsx`):** duas ações "Ver Setups" e "Salvar Novo Setup" visíveis sem scroll, mobile-first; páginas placeholder para as demais rotas (substituídas nas fases 2–3).
6. **Testes:** `src/storage.test.ts` (vitest) cobrindo CRUD de setup, normalização de tag, duplicate, contagem de uso.
7. **Verificação:** `npm test` verde + `npm run build` sem erros de TS.

## Must-haves (critérios da fase)

- [ ] Home mostra as duas ações sem scroll em desktop e mobile
- [ ] Rotas navegam sem erro
- [ ] Storage sobrevive a reload (localStorage)
- [ ] `npm run build` compila sem erros
