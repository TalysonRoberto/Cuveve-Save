# Plano 02-01: Pedaleira Visual

**Fase:** 2 — Pedaleira Visual
**Objetivo:** Knob interativo (contínuo e snap), ParamField (knob + input + toggle), Pedalboard fiel ao Cuvave.
**Requisitos cobertos:** KNOB-01..08, NFR-02

## Tarefas

1. **`src/components/knobMath.ts`:** faixa angular −135°..+135°; `valueToAngle`, `angleToValue` (com clamp+round), `snapAngle` (9 posições), `pointerAngle` (atan2 a partir do centro, sentido horário a partir das 12h). Testes em `knobMath.test.ts`.
2. **`src/components/Knob.tsx` (SVG):** dome circular com LED interno na cor do grupo (cinza quando desativado), linha indicadora rotacionada; anel com 9 pontos clicáveis nos knobs de posição (sem anel no VOLUME); drag rotativo por pointer events; teclado (setas/Home/End) com `role="slider"` + aria; roda do mouse.
3. **`src/components/ParamField.tsx`:** label do parâmetro + Knob + input numérico (sincronia bidirecional, clamp na faixa, bloqueia fora da faixa) + toggle Ativo/Desativado; desativado = cinza + opacidade + selo "OFF" (não só cor), valor preservado.
4. **`src/components/Pedalboard.tsx`:** painel preto do pedal com marca CUVAVE, fileira dos 10 ParamFields nas cores do grupo (scroll horizontal no mobile), 3 footswitches A/B/C **decorativos** (aria-hidden, sem letras de banco).
5. **`SetupEdit`:** renderiza o Pedalboard com estado local de `Parametros` (default 0/ativo) — base da tela de criação que a Fase 3 completa com nome/tags/salvar.
6. **Verificação:** `npm test` (knobMath + storage) verde, `npm run build` limpo.

## Must-haves (critérios da fase)

- [ ] Arrastar knob atualiza o campo em tempo real; digitar gira o knob
- [ ] Snap nos 9 pontos; VOLUME livre 0–100
- [ ] Desativar deixa cinza imediato/reversível, preservando valor
- [ ] Ordem e cores fiéis ao pedal; adapta a mobile
